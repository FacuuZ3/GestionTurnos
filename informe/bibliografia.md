# Bibliografía

Las fuentes están agrupadas por tipo. Para libros y artículos académicos
se utiliza un formato cercano a APA; para documentación oficial y
recursos web, se incluye el título, el productor y la URL de consulta.

## Libros y artículos académicos

- Fielding, R. T. (2000). *Architectural Styles and the Design of
  Network-based Software Architectures* [Tesis doctoral, University of
  California, Irvine]. Capítulo 5 introduce formalmente el estilo
  arquitectónico REST.

- Cahill, M. J., Röhm, U., & Fekete, A. D. (2008). Serializable
  isolation for snapshot databases. *ACM Transactions on Database
  Systems*, 34(4), 1–42. Artículo seminal de Serializable Snapshot
  Isolation (SSI), implementado posteriormente en PostgreSQL 9.1.

- Martin, R. C. (2008). *Clean Code: A Handbook of Agile Software
  Craftsmanship*. Prentice Hall. Referencia para los principios SOLID
  y prácticas de código limpio.

- Evans, E. (2003). *Domain-Driven Design: Tackling Complexity in the
  Heart of Software*. Addison-Wesley. Referencia conceptual para la
  separación entre capa de dominio y capa de infraestructura.

- Newman, S. (2021). *Building Microservices: Designing Fine-Grained
  Systems* (2.ª ed.). O'Reilly. Capítulos sobre comunicación
  asincrónica vía eventos y patrones de outbox.

- Gamma, E., Helm, R., Johnson, R., & Vlissides, J. (1994). *Design
  Patterns: Elements of Reusable Object-Oriented Software*.
  Addison-Wesley. Catálogo canónico de los patrones Strategy y
  Observer aplicados en el proyecto.

## Estándares y RFCs

- Internet Engineering Task Force (IETF). (2015). *JSON Web Token
  (JWT)*. RFC 7519. https://datatracker.ietf.org/doc/html/rfc7519

- Internet Engineering Task Force (IETF). (2014). *Hypertext Transfer
  Protocol (HTTP/1.1)*. RFC 7230–7235.

- ISO/IEC. (2016). *Information technology — Database languages — SQL —
  Part 2: Foundation*. ISO/IEC 9075-2:2016. Niveles de aislamiento
  transaccional.

- Open API Initiative. (2024). *OpenAPI Specification 3.1.0*.
  https://spec.openapis.org/oas/v3.1.0

- Open Web Application Security Project (OWASP). (2023). *Authentication
  Cheat Sheet*. https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html

- Open Web Application Security Project (OWASP). (2023). *JSON Web Token
  for Java Cheat Sheet*. Lineamientos sobre el uso seguro de JWT,
  aplicables a cualquier lenguaje.

## Documentación oficial de tecnologías

- **NestJS**. https://docs.nestjs.com — Framework de aplicación
  modular para Node.js utilizado en el backend.

- **Next.js**. https://nextjs.org/docs — Framework React con SSR y
  App Router utilizado en el frontend.

- **Prisma**. https://www.prisma.io/docs — ORM type-safe para Node.js
  y TypeScript.

- **PostgreSQL 16**. https://www.postgresql.org/docs/16/ — Motor de
  base de datos relacional. Particular relevancia: capítulo 13
  (*Concurrency Control*).

- **TypeScript**. https://www.typescriptlang.org/docs/ — Lenguaje
  principal del proyecto.

- **React**. https://react.dev/reference — Biblioteca de UI.

- **TanStack Query**. https://tanstack.com/query/latest/docs — Cache
  y sincronización de estado servidor.

- **Tailwind CSS**. https://tailwindcss.com/docs — Framework CSS
  utility-first.

- **React Hook Form**. https://react-hook-form.com — Manejo de
  formularios.

- **Zod**. https://zod.dev — Validación de esquemas con inferencia de
  tipos.

- **Playwright**. https://playwright.dev/docs/intro — Framework de
  tests end-to-end para navegadores.

- **Jest**. https://jestjs.io/docs — Framework de tests unitarios
  para JavaScript/TypeScript.

- **Docker Compose**. https://docs.docker.com/compose/ — Orquestación
  de contenedores para desarrollo local.
